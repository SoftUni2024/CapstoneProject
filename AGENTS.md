# CapstoneProject instructions

We are building a Hotel Booking System for the SoftUni "Software Technologies with AI" capstone project.

## Technology stack

- HTML, CSS and vanilla JavaScript ES modules.
- Bootstrap.
- Node.js, npm and Vite.
- Supabase Database, Auth and Storage.
- Render Static Site deployment.
- No TypeScript, React or Vue.

## Application scope

- Public hotel browsing and availability search.
- Guest registration, login and logout.
- One physical room per reservation.
- Immediate confirmation when inventory is available.
- EUR prices and pay at hotel.
- Guest booking history and eligible cancellation.
- Admin management of hotels, room types, physical rooms, images and reservations.

## Architecture

- Genuine multi-page application with separate HTML entry files.
- Shared components, services and utilities.
- Database-enforced access control and booking integrity.
- Committed SQL migrations synchronized with remote migration history.

## Implementation rules

- Implement only the current milestone.
- Never invent credentials or deployment URLs.
- Never expose privileged keys in browser code.
- Render user content safely.
- Use accessible, responsive interfaces.
- Verify version-specific APIs against official documentation.
- Report checks honestly.

## After each successful milestone

- Run relevant checks and build when available.
- Review the diff.
- Commit only the milestone's changes.
- Push to the configured remote if available.
- Never force-push, backdate commits or manufacture Git history.

Do not implement application features until a milestone explicitly authorizes them.
